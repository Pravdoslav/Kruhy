# Zdroj rukopisu

`Kruhy-1.0d.docx` je nezmenená archívna kópia Word rukopisu, z ktorej bol 2. augusta 2026 vytvorený webový text.

Aktuálnym zdrojom webu sú súbory `.qmd` v priečinku `book/`. Práve tie upravuj pri ďalších verziách; Word dokument zostáva referenčnou kópiou pôvodného rukopisu.

Skript `tools/import_docx.py` umožňuje opakovať technický import budúcej Word verzie. Pred jeho spustením treba vždy porovnať a zálohovať existujúce kapitoly, pretože ich znovu vytvorí z Word dokumentu.
